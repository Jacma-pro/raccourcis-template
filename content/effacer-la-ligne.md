## Faire place nette

Dans un terminal avec Bash ou Zsh et les raccourcis Emacs habituels, **Ctrl + U** efface le texte entre le début de la ligne et le curseur.

Essayez en saisissant cette commande **sans la lancer**, puis appuyez sur le raccourci :

```bash
git status --short
```

> Le comportement dépend du shell et de sa configuration clavier.

## Retrouver une information

Appuyez sur **Ctrl + F** (ou **Cmd + F** sur macOS), puis saisissez le texte à chercher.

- **Entrée** : occurrence suivante.
- **Maj + Entrée** : occurrence précédente.
- **Échap** : fermer la recherche.

## Ajouter une image à votre fiche

Remplacez l’URL ci-dessous par celle d’une image accessible sur le Web :

```markdown
![La barre de recherche du navigateur](https://exemple.org/capture.png)
```

Le texte entre crochets décrit l’image. L’image apparaîtra directement dans la fiche une fois cette ligne ajoutée hors du bloc de code.

## À quoi ça sert ?

La palette permet de rechercher et d’exécuter une commande : changer le thème, formater un document, lancer une action Git…

1. Appuyez sur **Ctrl + Maj + P** sous Windows ou Linux.
2. Sous macOS, utilisez **Cmd + Maj + P**.
3. Tapez le nom d’une commande puis validez avec **Entrée**.

> Astuce : cherchez « Format Document » pour formater le fichier courant.

[Documentation de VS Code](https://code.visualstudio.com/docs/getstarted/userinterface#_command-palette)
